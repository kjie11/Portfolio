Gothic Hunter

Gothic Hunter is a short-session top-down survival game built in Godot. A finite three-act run combines four evolving weapons, two ultimates, elite encounters, a final boss, and input abstraction for keyboard and wearable gesture control.

The project focuses on making weapon growth and combat pressure readable under dense enemy and projectile loads. Runtime telemetry, repeatable debug jumps, capture reviews, and performance tests were used to tune the full experience rather than treating a compiling build as finished.

Key Features

  • Defined a deterministic three-act survival run with a finite enemy budget and boss finale
  • Designed four simultaneous weapons with four visible growth stages and distinct combat roles
  • Mapped wearable gestures to movement, directional shots, and ultimate actions with keyboard parity
  • Directed pacing changes through full-run telemetry, weak-player regression tests, and capture review
  • Validated high-pressure rendering with pooled enemies, projectiles, effects, and streamed world tiles

Design Focus

  • Keep weapon growth, enemy pressure, and combat feedback readable during dense encounters
  • Use one gameplay language for keyboard and wearable gesture input
  • Shape a finite, testable run instead of an open-ended survival loop
  • Keep player balance, final assets, target-device performance, and real glove input pending
