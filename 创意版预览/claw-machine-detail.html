Claw Machine

P.03 / INTERACTION PROTOTYPE

A claw-machine prototype where success depends on maintaining the right grip window, not only positioning the claw.

ROLEInteraction design & development
ENGINEUnity
INPUTGrip force / keyboard
STATUSPrototype; tuning pending

Grip becomes the game.

I independently built the prototype to turn grip strength into a learnable gameplay window. Keyboard simulation keeps the full interaction loop testable while final hardware input tuning remains separate.

01 / INPUT

Force window

Configurable grip profiles define the target range for different toys.

02 / SYSTEM

Failure logic

Continuous out-of-range input can release the toy instead of treating every grab as binary.

03 / FEEDBACK

Readable force

Radial feedback makes the current grip state visible during play.

04 / RESPONSE

Physical contact

Animated recovery paths and collision-deformation experiments give contact a visible consequence.

Current validation boundary

The prototype and its interaction logic are implemented. Final real-glove feel, end-to-end latency, and hardware tuning remain follow-up work, so this page presents it as an independently built prototype rather than a shipped product.
