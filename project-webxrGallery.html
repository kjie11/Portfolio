WebXR Multimodal Gallery

This personal mobile WebXR gallery combines rotation, gaze, shake, voice, and gesture input in one immersive experience. The project explores how several modalities can support a gallery visit without creating conflicting controls or inconsistent feedback.

Usability testing informed feedback iteration. The available record confirms the prototype and testing direction, while the technical stack, participant count, compatibility coverage, performance, and detailed conflict rules remain pending evidence.

Key Features

  • Mobile WebXR gallery prototype
  • Rotation, gaze, shake, voice, and gesture input
  • Feedback iteration informed by usability testing

Design Focus

  • Choose appropriate modalities for different gallery actions
  • Reduce input conflict and keep feedback consistent across modalities
  • Treat mobile compatibility and performance as pending validation rather than assumed support

Validation

  • Designed, implemented, and usability-tested personal prototype
  • Participant count, device matrix, performance results, and detailed findings remain unavailable
