# Detail Page Topology

1. Full-width top navigation, static in flow.
2. Hero media, 16:9, bounded to 1200px.
3. Two-column detail grid: header and narrative on the left, sticky project facts and actions on the right.
4. Optional project-video section with external watch link and 16:9 embed.
5. Optional source evidence images in the narrative column.
6. Previous / all projects / next footer navigation.

The low-fi home panel is preserved. The cloned detail panel is a sibling state, not a modal or nested card.
