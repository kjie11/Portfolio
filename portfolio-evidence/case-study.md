# Initial Portfolio Additions

Four local projects were added to the existing static portfolio without changing its layout or CSS. Each project reuses the existing gallery-card and single-column detail-page pattern.

## Gothic Hunter

**Thesis:** A wearable-input game brief became a complete Godot survival prototype with a deterministic run, recorded proof, and repeatable performance validation. [CLAIM-001]

**Key Work**

- Defined a finite three-act run and boss finale
- Designed four visibly evolving weapon systems
- Mapped wearable gestures to stable gameplay semantics
- Tuned difficulty through telemetry and regression runs
- Validated dense combat against a 60 FPS target

## Four-Way Kitchen

**Thesis:** One cooking loop supports keyboard, EMG, camera, and wearable input without changing its gameplay rules. [CLAIM-002]

**Key Work**

- Designed a four-sided functional kitchen layout
- Built processing, cooking, plating, throwing, and delivery
- Defined deterministic four-direction item transfer
- Unified four input paths behind shared actions
- Added disconnect and stale-state recovery rules

## Hand-Input Claw Machine

**Thesis:** Grip strength becomes a learnable control challenge through configurable force windows, visible feedback, and explicit recovery behavior. [CLAIM-003]

**Key Work**

- Defined two-hand positioning and force control
- Designed the complete claw-state sequence
- Created configurable per-prize force windows
- Built radial current-versus-target feedback
- Separated hardware adapters from gameplay logic

## Mole Rhythm

**Thesis:** A five-finger interaction concept became a reproducible rhythm prototype with ergonomic chart constraints and DSP-timed judgment. [CLAIM-004]

**Key Work**

- Mapped five mole lanes to five fingers
- Defined novice-friendly ergonomic chart rules
- Built deterministic offline chart generation
- Simplified audio scope around the available track
- Unified keyboard and wearable judgment input
