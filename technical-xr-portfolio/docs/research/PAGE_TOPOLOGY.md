# Technical portfolio page topology

## Index route (`/technical/`)

1. Fixed utility navigation: identity, portfolio mode, language switch.
2. Compact intro band: technical positioning and current project count.
3. Responsive masonry work index: five media-first project cards.
4. Minimal end mark and contact/resume placeholders.

Each card contains only the project media plus a hover/tap overlay with the project title and one-line role. The existing premise, capabilities, status, and workflow content move to the detail route.

## Detail route (`/technical/#/project/:slug`)

1. Fixed utility navigation.
2. Centered hero media: video, image, or explicit video placeholder.
3. Back command and project title.
4. Two-column information area: detailed overview and key work on the left; roles, technologies, project scale, and year on the right.
5. Optional supporting images.
6. YouTube proof area. All five current projects render a clear placeholder until final YouTube URLs are supplied.
7. Current status and compact footer.

## Media Classification

- Homepage card media: short muted preview video where available; still image where available; neutral video placeholder where missing.
- Detail lead media: the same project proof enlarged. Existing Gothic Hunter MP4 remains a real video; the other current images remain images until videos are supplied.
- YouTube: separate long-form proof below project text, never the homepage card target.
- Short introduction: title + premise/role in the card overlay and title area.
- Detailed introduction: technical angle, contribution list, capabilities, workflow, and current status on the detail page.
