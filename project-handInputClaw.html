Hand-Input Claw Machine

This Unity prototype turns a familiar claw machine into a two-hand force-control experience. The left hand positions the claw, while a right-hand grip starts the cycle and controls force after contact. Each prize can define a different successful force window.

The project separates input from gameplay so the full cycle can be tested with keyboard and mouse before hardware tuning. It also explores animated claw motion, stable object following, release-specific recovery, radial force feedback, and local visual deformation.

Key Features

  • Defined a two-hand interaction model that separates positioning, triggering, and continuous grip force
  • Designed the full claw cycle from targeting and descent through evaluation, delivery, release, and recovery
  • Created configurable force windows so different prizes can reward different grip strategies
  • Designed radial force feedback that compares current grip against a visible target region
  • Separated keyboard simulation and hardware adapters from the shared gameplay state machine

Design Focus

  • Turn grip strength into a learnable balance between control and risk
  • Separate positioning, triggering, and continuous force across two hands
  • Make success windows, failure states, and recovery paths visible and predictable
  • Keep real two-hand tuning, final result feedback, and object reset as pending validation
